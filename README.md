## Introduction

The Survex Data programming language is tailored for 2D data representation and manipulation. This IDE aims to streamline the coding process, making it easier for developers to write, test, and debug their code efficiently. With a user-friendly interface and powerful features, the IDE enhances productivity for both beginners and experienced programmers.

## Features

- **Syntax Highlighting**: Code is color-coded for easy reading.
- **Code Completion**: Get suggestions as you type to speed up coding.
- **Error Checking**: Immediate feedback on syntax errors.
- **Integrated Terminal**: Run your scripts without leaving the IDE.
- **Customizable Themes**: Choose a look that suits your style.
- **Project Management**: Organize your files and folders effectively.

## Usage

Once you have installed the IDE, you can start a new project or open an existing one. The main interface includes:

- **Editor**: Where you write your code.
- **Console**: Displays output and errors.
- **File Explorer**: Navigate through your project files.

### Creating a New Project

1. Click on "File" in the menu.
2. Select "New Project."
3. Name your project and choose a location to save it.

### Writing Code

In the editor, you can write your Survex Data code. Use the syntax highlighting and code completion features to enhance your coding experience.

### Running Your Code

To run your code, simply click the "Run" button or use the shortcut key (usually F5). The output will appear in the console.
